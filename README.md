Bộ 6 skill cho [Claude Code](https://claude.com/claude-code) giúp bạn dựng video bằng AI: từ file giọng đọc, từ video quay mặt nói chuyện, đến video quảng cáo bán hàng. Bạn chỉ cần nói việc muốn làm bằng lời thường, Claude sẽ dùng đúng skill.

## 6 skill trong bộ

| Skill | Dùng để |
|---|---|
| `tc-animation` | Video animation đồ họa phẳng (chữ, emoji, biểu đồ) từ một file giọng đọc |
| `tc-nguoi-que` | Video hoạt hình người que nét chì từ một file giọng đọc |
| `tc-edit-tu-a-z` | Dựng video từ A đến Z: cắt phần thừa, rồi phủ tiêu đề, phụ đề, hiệu ứng |
| `tc-edit-video-chia-se` | Phủ chữ và hiệu ứng lên video đã cắt sẵn, không cắt ghép |
| `tc-sub-editorial` | Phủ phụ đề kiểu tạp chí sang trọng lên video nói chuyện |
| `tc-quang-cao` | Video quảng cáo, khuyến mãi, giới thiệu quán 20–30 giây |

## Cài nhanh

1. Tải file zip ở trên và giải nén.
2. Mac hoặc Linux: chạy `bash install.sh`. Windows: chạy `install.ps1`.
3. Mở một phiên Claude Code mới.
4. Bấm đúp `LAY-MA-MAY` để lấy mã máy, rồi nhắn Tâm Cao để nhận mã kích hoạt.
5. Nói với Claude Code: "kích hoạt skill bằng mã này: ..." rồi dán mã.

Cần có Python 3.10 trở lên, ffmpeg, và Chrome hoặc Edge (tùy skill).

## Kích hoạt và dùng thử

Bộ skill cần mã kích hoạt riêng cho từng máy mới chạy được. Bạn có thể **dùng thử miễn phí 1 ngày** (mỗi máy một lần) trước khi mua. Chi tiết nằm trong `HUONG-DAN-MUA-SKILL.pdf` đi kèm gói.
