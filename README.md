# Bộ skill video của Tâm Cao

Bộ 6 skill cho [Claude Code](https://claude.com/claude-code) giúp bạn dựng video bằng AI: từ file giọng đọc, từ video quay mặt nói chuyện, đến video quảng cáo bán hàng. Bạn chỉ cần nói việc muốn làm bằng lời thường, Claude sẽ dùng đúng skill.

**Công dụng từng skill (có hình minh họa) và nút tải về:** [tcaoadm.com/6-tc-edit-video-skills](https://tcaoadm.com/6-tc-edit-video-skills)

> Repo này chỉ là trang giới thiệu. Gói cài đặt được tải ở website trên.

## 6 skill trong bộ

| Skill | Dùng để |
|---|---|
| `tc-animation` | Video animation đồ họa phẳng (chữ, emoji, biểu đồ) từ một file giọng đọc |
| `tc-nguoi-que` | Video hoạt hình người que nét chì từ một file giọng đọc |
| `tc-edit-tu-a-z` | Dựng video từ A đến Z: cắt phần thừa, rồi phủ tiêu đề, phụ đề, hiệu ứng |
| `tc-edit-video-chia-se` | Phủ chữ và hiệu ứng lên video đã cắt sẵn, không cắt ghép |
| `tc-sub-editorial` | Phủ phụ đề kiểu tạp chí sang trọng lên video nói chuyện |
| `tc-quang-cao` | Video quảng cáo, khuyến mãi, giới thiệu quán 20–30 giây |

## Cách dùng

1. Vào [tcaoadm.com/6-tc-edit-video-skills](https://tcaoadm.com/6-tc-edit-video-skills), bấm **Tải bộ skill về** và giải nén.
2. Cài: Mac hoặc Linux chạy `bash install.sh`, Windows chạy `install.ps1`. Rồi mở một phiên Claude Code mới.
3. Dùng skill ngay: **24 giờ dùng thử miễn phí tự bắt đầu, không cần mã.**
4. Hết 24 giờ, mỗi máy cần một mã kích hoạt riêng. Nhắn Tâm Cao để nhận mã, rồi nói với Claude Code: "kích hoạt skill bằng mã này: ...".

Cần có Python 3.10 trở lên, ffmpeg, và Chrome hoặc Edge (tùy skill). Trong gói có sẵn hướng dẫn chi tiết dạng PDF.
